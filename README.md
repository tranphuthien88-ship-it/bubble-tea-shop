# 🧋 Bubble Tea Shop

Full-stack web application for an online Bubble Tea Shop.

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Zustand

### Backend
- NestJS
- TypeScript
- JWT Authentication
- Mongoose

### Database
- MongoDB

### DevOps
- Docker
- Docker Compose
